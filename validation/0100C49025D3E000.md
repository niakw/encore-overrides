# FC 27 — Recommended candidate validation

Title ID: `0100C49025D3E000`

This test is intentionally performed **after** the profile has been derived from source-console/game data.

## Candidate

- Vulkan
- Docked
- 1.25x game resolution
- 1440p TV output
- Bilinear
- AA None
- 60 Hz
- target: stable 30 FPS

## Validation sequence

Use a standard PS5 with no manual per-game overrides beyond the candidate.

### 1. Cold boot / menus

- Launch Encore from cold.
- Launch FC 27.
- Navigate menus for at least 3 minutes.
- Record crashes, graphical corruption, abnormal stalls or input issues.

### 2. Match reproducibility

Play **two complete matches** using the same candidate without changing settings.

Record:

- FPS range during normal gameplay.
- Whether 30 FPS is sustained.
- major frame-time spikes/stutters.
- rendering corruption.
- audio desynchronisation.
- crash/freeze.
- image softness, shimmer or obvious aliasing.

### 3. Stress scene

Use a visually busy match/stadium scenario and record whether the profile still maintains acceptable pacing.

### Pass criteria

The candidate can advance only if:

- both complete matches finish without crash/freeze;
- gameplay remains effectively locked to the game's 30 FPS target;
- no persistent rendering defect appears;
- no severe frame-time instability appears;
- image quality is clearly acceptable at normal TV viewing distance.

### If it fails

Do **not** tune several parameters at once.

Use this diagnostic order:

1. keep 1440p output and reduce only game resolution from 1.25x → 1.0x;
2. if the problem is graphical rather than performance-related, test renderer separately;
3. only after isolating the limiting factor should a replacement Recommended candidate be authored.

The failed candidate stays documented; it is not silently rewritten as "validated".
